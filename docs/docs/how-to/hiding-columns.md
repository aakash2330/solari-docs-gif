# Hide a column

The table shows Task, Title, Status and Priority. Any column except Task can be taken
out of view without changing the underlying tasks.

1. Select **View** at the right-hand end of the toolbar, next to Add Task.
2. In the list of columns, clear the checkbox beside **Priority**.

The Priority column is removed from the table. Open **View** again and set the same
checkbox to bring it back.
