# Change a task's label

A label marks what kind of work a task is: documentation, a bug, or a feature. It is
set from the task's own row, not from the toolbar.

1. Find the row you want to change. **TASK-8782** is the first row in the list.
2. At the right-hand end of that row, select the **⋮** button.
3. Point at **Labels** to open the second menu.
4. Select **Bug**.

The badge next to the task's title changes from Documentation to Bug.
