# Mark several tasks done at once

Ticking rows turns on bulk actions in the toolbar, so a batch of tasks can be closed
in one go.

1. Tick the checkbox at the left-hand end of the first row, **TASK-8782**.
2. Tick the checkbox on the second row, **TASK-7878**.
3. Select **Mark done** in the toolbar. It appears only while rows are ticked.

Both rows now show the status Done and their checkboxes are cleared. **Delete
selected**, beside Mark done, removes ticked rows in the same way.
