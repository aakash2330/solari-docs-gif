# Sort tasks by priority

Any column whose name carries a pair of small arrows can be sorted.

1. Select **Priority** in the table header, at the top of the column.
2. In the menu that opens, select **Asc**.

The arrows beside Priority become a single upward arrow, and every task marked High
moves to the top of the list. Choose **Desc** in the same menu to reverse it.
