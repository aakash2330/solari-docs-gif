# Copy a task

A copy keeps everything but the ID, and sits directly under the original.

1. Find the row you want to copy. **TASK-8782** is the first row in the list.
2. At the right-hand end of that row, select the **⋮** button.
3. Select **Make a copy**.

A second row with the same title, status and priority appears immediately below
TASK-8782, carrying a new ID.
