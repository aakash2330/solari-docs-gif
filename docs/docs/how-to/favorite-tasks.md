# Star a task and show only starred tasks

Each row has a star beside its checkbox. Starred tasks can be shown on their own from
the toolbar.

1. Select the star on the first row, **TASK-8782**. It fills in yellow.
2. Select **Favorites** in the toolbar, to the right of Priority.

The table shrinks to the starred rows only, and a **Reset** button appears at the end
of the filter row. Select it to bring the other tasks back. The star can also be set
from the row's **⋮** menu with **Favorite**.
