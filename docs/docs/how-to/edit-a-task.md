# Edit a task

Status, priority, label and title can all be changed from one dialog, opened from
the task's own row.

1. Find the row you want to change. **TASK-8782** is the first row in the list.
2. At the right-hand end of that row, select the **⋮** button.
3. Select **Edit**.
4. In the dialog, select the **Status** field and choose **Done**.
5. Select **Save changes**.

The row's status now reads Done. The dialog closes and nothing else in the list
moves.
